# 两个在线基线完成 100 轮后的验证对照

2026-10-12。固定图 ProTAS 的 100 轮训练已完整结束。仅使用验证集评价与诊断，不使用测试结果选择方向。

## 训练收益

ProTAS 按既定 `(canonical Edit + F1@50)/2` 选中第 75 轮：Edit=52.29、F1@50=41.10，相较原 50 轮实验最佳的 37.07 提高约 4.03 个 F1 百分点。第 75 轮后未刷新最佳；91–100 轮平均选模分数 41.68，低于 71–90 轮的 42.33。支持当前先停止延长训练，不能据此保证更长预算绝无收益。

固定任务图全程最大初始漂移均为 0。原始类别输出验证 F1@50=41.03，任务图调整后为 41.10，差异很小，不能将整体收益归为任务图推理解码。

## 用 best 权重重新推理后的错误分析

77 条验证序列，67,262 帧、545 个前景真值片段，原始结果和 checkpoint 哈希保存在 `validation_comparison_e100/comparison.json`。

| 描述性错误 | MS-TCN | ProTAS |
|---|---:|---:|
| GT 无同类预测时间重叠 | 144 / 545（26.42%） | 178 / 545（32.66%） |
| GT 内多个同类预测片段 | 50 / 545（9.17%） | 34 / 545（6.24%） |
| 预测前景片段数 | 911 | 730 |
| 前景误判背景帧 | 8,496 | 10,635 |
| 背景误判前景帧 | 3,924 | 3,281 |
| 前景误判其他动作帧 | 9,858 | 9,618 |

漏检定义为真值片段内没有任何同类预测时间重叠，区别于 IoU@50 匹配失败，不能直接当作标准检测漏检率。片段较少也不等于所有冗余片段均被正确消除。

同一个真值逐一配对：两者均漏 98 个，仅 MS-TCN 漏 46 个，仅 ProTAS 漏 80 个，两者均有同类覆盖 321 个。1–30 帧组均漏 25 个，31–60/61–120/>120 帧组 ProTAS 漏检分别为 64/67/22，MS-TCN 为 52/49/18。因此本次差异不能表述为“ProTAS 特别容易漏最短动作”。

两者共同完成同类 IoU≥0.1 匹配的 305 个真值片段中，起点绝对误差中位数为 5/6 帧，终点均 6 帧；起点有符号偏移均 +3 帧。这是成功匹配条件下的描述，不包含漏检动作，不是实时延迟实验。

类别转换边界 ±10 帧之外分别包含 64.41% / 65.93% 的全部错帧，且前景其他类别混淆仍占错误较大比例。因此仅增加边界平滑或确认等待无法被这些结果支持为充分方案。

## 下一步判断

1. 不继续机械增加这两个在线基线的轮数；保留已完成的同 100 轮验证对照。
2. 下一步针对“因果时序建模下的前景类别证据、召回与片段稳定性”核查方法机制和文献，不预先假定边界头或某个网络模块必然有效。
3. 若以 ProTAS 为改进主干，应同时观察前景准确率、漏检、碎片和 F1；不能仅凭 F1 上升接受更严重漏检。MS-TCN 保留为在线对照。
4. SpecScalpel 为离线参照，未来信息、输入和训练预算不同；验证差距不能全部归因于因果约束。

本轮没有启动新训练或执行测试集评价。分析脚本已支持指定两个 run 和新报告目录，保留旧 50 轮报告。新示例页为 `validation_comparison_e100/cases.html`，确定性选例只辅助理解，不代表总体分布。
