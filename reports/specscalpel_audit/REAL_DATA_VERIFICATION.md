# SpecScalpel 真实数据小批验证

2026-10-12，分支 `analysis/specscalpel-audit`。结论：已通过训练链路验证，可以进入小规模多轮训练；尚无有效精度结论。

## 本轮实际完成

- 在 dest_gpu 中安装 torchvision 0.23.0+cu126，保留 torch 2.8.0+cu126；`pip check` 通过。
- 下载固定官方提交的动作和关节文本嵌入，分别为 52×768、25×768，记录下载地址、大小与 SHA256。未下载预训练模型。
- 由现有 `configs/dest_compat.json` 生成官方 dataset 可读取的训练与验证 CSV，保留 698/77/234 划分，禁止三个集合交叉。训练适配目录不生成测试 CSV，也不加载测试数组。
- 调用原版 Dataset、变换、增广、Model 和 helper.train，保留原版完整损失：分类 CE/GSTMSE、边界 BCE、动作文本对比以及相邻动作频域差异。边界正样本权重只从 698 条训练标注计算，值约 73.9191。
- 唯一运行兼容替换：边界峰值提取中的旧 `np.bool` 改用等价 `np.bool_`；在本地适配层替换函数，不修改官方快照。
- 验证端接入现有统一 Meter，分别记录原始逐帧输出与原版边界后处理输出；另记录现有 ProTAS 补充口径。后者不是 SpecScalpel 官方评价器。未来多轮选模继续使用原始输出 `(canonical Edit + F1@50)/2`，本轮没有选模。

## 运行结果

| 检查 | 4 条训练 / 2 条验证 | 24 条训练 / 8 条验证 |
|---|---:|---:|
| 完整序列训练更新次数 | 2 | 12 |
| 平均完整训练损失 | 5.9318 | 5.1951 |
| 训练部分耗时 | 6.46 秒 | 28.13 秒 |
| 整个检查的 CUDA 峰值已分配显存 | 约 1.16 GiB | 约 1.16 GiB |
| 分类、边界、对比损失有限 | 通过 | 通过 |
| 全部已产生梯度有限且范数非零 | 通过 | 通过 |
| 权重保存、严格重载与验证输出一致 | 通过 | 通过 |

使用 RTX4090D、batch size 2、seed 17、完整序列、不裁剪。模型和损失保留原版默认结构；本轮 batch size 与作者默认 8 不同，因此不能称为论文实验完整复现。计时不含数据清单/资产准备，不能据此直接估算 300 轮耗时或最长序列显存。

24 条训练后，8 条验证的 Acc=42.64%，前景准确率=0，Edit=0、F1@50=0，仍为背景预测。4 条版本同样如此。两次独立运行的平均损失不可当作同一次训练的下降曲线；单轮仅 12 次更新也不足以证明模型有效或无效。

## 尚未验证

没有完整训练、论文精度复现、测试评价或在线化。没有验证 batch size 8 的显存，也没有覆盖全部序列的数值边界情况。保留官方离线前向位移预处理和文本先验，所以这里只统一数据划分与评价口径，不宣称输入变换与因果 MS-TCN 完全相同。

下一步应做固定小训练集的多轮学习检查，观察训练损失、前景预测比例、前景准确率和 Edit/F1 是否随训练改善；若持续全背景，再排查训练与监督，而不是直接投入 300 轮。
