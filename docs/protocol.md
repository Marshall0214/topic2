## 训练/验证关系与两套清单

文件名均不跨切分重复，测试受试者与训练/验证分离。但 train1/val1 有 77 个共同的 AxxNxx 基础采集编号，即同次动作的不同视角。此处依据文件名去掉视角后缀，尚未核实相机序列是否严格同步。它有验证相关性风险，不等同测试集泄漏，也不能据此量化旧结果虚高多少。

- `configs/dest_compat.json`：保持 DeST 上游 698/77/234，供协议兼容对照。旧训练列表确实与该协议匹配。
- `configs/recording_holdout_seed17.json`：本地分组验证候选，合并上游 train+val 后按 AxxNxx 分组，选 26 次采集做验证，得到 699/76/234。选择仅用开发池标签覆盖和固定种子打破并列，验证覆盖开发池实际存在的全部类别；测试不参与划分选择。不同视角不得跨训练/验证。

后续方法开发优先分组验证协议；与既有结果兼容时单独运行 dest_compat。两个协议不能混表或据分数高低挑选。新清单未改上游 CSV。正式测试保留同一 234 条，但这些数据在历史探索和官方权重评价中已被查看，不能宣称是从未接触的全新盲测集。

## 在线输入、模型与输出

先固定无额外等待：y_t 仅依赖 x_1:t，输出后不回填。模型与输入预处理都须因果。动作片段由类别切换形成；尚未结束的片段只报告当前已观测部分，不能假装知道最终结束点。

2026-10-12 阶段 B 已实现共享 300 维输入、两套评价器和训练入口，见 README.md。已通过合成输入和 GPU 短训练验收；尚未开展 24/8 小规模正式筛查。前景双方均为空的序列 Edit=100，全为空的前景 F1=0；F1 使用跨序列汇总计数。

输入首版建议采用每人的当前根相对坐标与后向位移，展开为 300 维，首帧位移为零。每人分别判定有效性，身体缺失时该人的坐标/位移置零，相邻任一时刻无效则该人的位移置零。不可照搬 DeST 上游将 x[t+1]-x[t] 写在时刻 t 的前向差分。该方案是本地骨架适配，不是已确认的 DPTM 表 7 输入细节；若后续获取其官方实现，应单独建立严格复现配置。

当前可执行的已有在线来源为 ProTAS。MS-TCN 官方原版使用对称卷积，需参考 ProTAS 的因果卷积实现建立基础对照。ProTAS 即使关闭图模块仍有进度 GRU 和融合头，不能把 `--graph` 关闭后的模型叫普通 MS-TCN。

ProTAS 任务图只可由训练清单中的标签构建。原脚本扫描整个 groundTruth 目录，移植时必须显式接收训练清单；训练阶段进度监督可使用训练动作的完整边界，推理不得读取真实进度或真实边界。

## 指标约定

同时保留并明确命名两种背景口径：

1. `dest_legacy`：兼容上游 mapping 的 NONE 与原评测实现；不能称为排除背景。上游最后片段结束索引使用 T-1，也须注明。
2. `foreground_canonical`：Acc 包含全部有效帧，Edit 与 F1@10/25/50 显式排除 ID 0；区间一律半开 [start,end)，最后片段结束为 T。Edit 按序列平均，F1 汇总所有序列 TP/FP/FN。空前景序列约定须写入评测代码并测试。

前景口径用于方法诊断，兼容口径用于解释历史结果。ProTAS 原评测的 Edit 在删除背景帧后再次合并同类，而 DeST 先按片段提取标签，两者在 A-background-A 情形不同；不能未经验证认为两套 Edit 相同。DPTM 具体采用哪个实现尚未确认。

候选模型选择在同一验证协议、同一主指标上进行。测试结果和原文数字不用于调参。基线之间统一输出支持范围；不得依真实动作边界裁剪或重置缓存。
